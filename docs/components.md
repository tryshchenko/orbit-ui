# Component API overview

Full, interactive prop tables live in Storybook (**Docs** tab of each component, generated from the TypeScript types). This page is a map of what exists and how the pieces fit.

Conventions used by every component:

- Typed props and exported `…Props` types. Refs forward to the main DOM node.
- `className` and standard DOM props pass through.
- Controlled **and** uncontrolled (`value` / `defaultValue` / `onValueChange`, `open` / `defaultOpen` / `onOpenChange`) where state exists.
- Visual variants via `class-variance-authority` (`buttonVariants`, `badgeVariants`, `cardVariants`, `glassPanelVariants` are exported for reuse).
- Overlays portal into the ThemeProvider's container, so scoped themes work.
